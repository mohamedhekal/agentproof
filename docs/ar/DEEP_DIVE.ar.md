**ورقة عمل مش قصة.** الحقائق والأرقام لازم تيجي من النظام الحقيقي؛ مفيش حاجة هنا مخترعة. املا كل فراغ بحاجة تقدر تفتحها قدام اللي بيسألك (log، dashboard، commit، query). لو ما تقدرش تورّيها، شيلها. الـ deep dive التقني الطويل بيكافئ اللي يقول "ده الـ query" وبيعاقب اللي يقول "تقريباً".

احتفظ بالنسخة اللي هتملاها **بره أي ريبو public**: هيبقى فيها تفاصيل حوادث حقيقية.

اربط كل فشل بفئة. AgentProof فيه سيناريو لكل فئة، وده بيدّيك demo تاني قابل للتكرار:

| الفئة | مثال للعَرَض | سيناريو AgentProof |
|---|---|---|
| retry مش idempotent | عميل اتأكد له الطلب أو اترجّع له مرتين بعد timeout أو webhook مكرر | `damaged_small_refund` و`already_refunded` تحت chaos |
| الوثوق في نص مش موثوق | تعليمة جوه رسالة عميل أو ملاحظة طلب اتنفّذت | `prompt_injection_in_order_note` |
| التصرف من غير صلاحية | الـ agent عمل حاجة كانت محتاجة بني آدم | `damaged_high_value` و`delivered_but_not_received` |
| رد tool مشوّه بصمت | رد API فاضي أو مشوّه اتعامل كنجاح | عطل القراءة `malformed` |
| ذاكرة قديمة أو متناقضة | الـ agent اتصرف على عنوان أو سعر اتغيّر أو متنازع عليه | `agentproof brain` |
| وقوع dependency | الموديل أو الـ gateway وقع، والـ agent اتجمّد أو خمّن | trace الـ fail-safe |

## 3. إزاي تلاقي مرشّحينك

دوّر في تاريخ الـ commits وملاحظات الحوادث وتصعيدات الدعم على: بدائل ضفتها لما موديل أو provider وقع، أخطاء parsing أو تسعير عملها الـ agent، تخفيضات tokens أو تكلفة، أماكن ممكن ملاحظات داخلية توصل فيها لجمهور غلط، وكل قاعدة من نوع "ده لازم بني آدم يوافق عليه". كل قاعدة من النوع ده قرار human-in-the-loop: اكتب الحادثة اللي خلّتك ترسم الخط. دي أحسن مادة لـ "approvals that pull a human in at exactly the right moment".

## 5. أسئلة تتمرّن عليها

1. "احكيلي أسوأ حادثة." ابدأ بالعَرَض اللي المستخدم شافه، وخلّص بالحماية اللي بتمنعه دلوقتي.
2. "عرفت إزاي إن الـ agent بنفس الاعتمادية في التشغيلة 50 زي الأولى؟" (pass^k، chaos بـ seeds، idempotency؛ مش accuracy على مجموعة نضيفة.)
3. "إيه اللي ما كنتش هتسيب الـ agent يعمله، وليه؟" (سمّي الخط، وبعدين الحادثة اللي وراه.)
4. "إيه اللي هيتكسر الأول لو الحجم زاد 10 أضعاف؟" (التكلفة، rate limits، طابور البشر، تناقضات الذاكرة.)
5. "إيه اللي قِستُه وفاجئك؟"
